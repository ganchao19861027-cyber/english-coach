# 英语教练 · English Coach

一个可以装到 iPhone 主屏幕、离线可用、可联网更新的英语学习应用（PWA）。
面向「有一点基础、但开不了口」的学习者，用 180 天把日常口语和
暖通空调（HVAC）／楼宇自控（BAS）专业英语一起练起来。

## 在线地址（iPhone 上打开这个）

**https://ganchao19861027-cyber.github.io/english-coach/**

同目录下的 `安装二维码.png` 可以直接用 iPhone 相机扫码打开。

## 30 秒开始

1. 用 **iPhone Safari** 打开应用地址（或用电脑双击 `启动本地预览.command`）。
2. 点底部 **分享** 按钮 → **添加到主屏幕**。
3. 主屏幕出现「英语教练」图标，点开即全屏运行，**断网也能用**。

## 学习法

- **刻意练习**：每句跟读即时打分，显示漏读词，要求练到 85 分以上。
- **间隔重复**：单词按 15 分钟 → 1 天 → 3 天 → 7 天 → 16 天 → 38 天安排复习。
- **主动回忆**：闪卡先回忆再翻面；闯关题目由内容库实时生成。
- **组块化 / 费曼技巧**：背句型框架、录讲解演练。

## 目录结构

```
index.html            应用入口
manifest.webmanifest  PWA 清单（图标、启动方式）
sw.js                 Service Worker（离线缓存 + 内容更新）
css/app.css           设计系统与全部样式
js/app.js             外壳：路由、标签栏、引导流程
js/core/              状态存储、语音、点读、出题、组件
js/data/              课程内容（词库、对话、句型、专业资料、180 天计划）
js/views/             七个主页面
icons/                应用图标与 iOS 启动图
tools/                本地预览服务器、发布脚本
docs/                 安装指南与界面截图
```

## 本地开发

```bash
node tools/serve.mjs 8788      # 打开 http://localhost:8788/
```

内容都在 `js/data/` 下，直接改文件、刷新页面即可看到效果。
改完内容记得把 `sw.js` 里的 `VERSION` 加一，用户端才会更新。

## 发布到 GitHub Pages

```bash
bash tools/deploy-pages.sh english-coach
```

当前线上地址即由该脚本发布（仓库：`ganchao19861027-cyber/english-coach`）。
不想保留时，执行 `gh repo delete ganchao19861027-cyber/english-coach` 即可删除。

## 说明

- 学习记录保存在设备本地（localStorage），不上传服务器；联网查词只发送你点击的那个单词。
- 语音朗读使用系统语音引擎（离线可用）；语音识别评分需要系统开启键盘听写。
- 专业模块为通用行业英语学习资料，产品名称与参数请以厂商官方最新资料为准。
