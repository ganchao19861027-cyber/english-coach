# 安装到 iPhone（3 分钟）

## 一、准备工作

- 一部 iPhone（iOS 16 及以上体验最佳）
- 应用地址：发布后类似 `https://<你的用户名>.github.io/english-coach/`
- 请务必使用 **Safari** 打开（微信、QQ、Chrome 的内嵌浏览器不支持"添加到主屏幕"）

## 二、安装步骤

1. **打开链接**：在 Safari 地址栏输入网址并打开。
2. **点击分享**：屏幕底部中间的方框向上箭头图标。
3. **添加到主屏幕**：在弹出菜单里向下滚动，找到"添加到主屏幕"，点击右上角"添加"。
4. **开始使用**：主屏幕出现"英语教练"图标，点开后是全屏应用，没有浏览器边框。
5. **首次使用建议**：完整走一遍"今日任务"（听一段、读一段、做一局闯关），
   让应用把全部内容缓存到手机里，之后**断网也能正常学习**。

## 三、每日提醒（iPhone 上最可靠的做法）

网页应用无法在后台自己发通知，用下面的方式可以让提醒稳定出现：

### 方法一：写入系统日历（推荐）

1. 打开 App →「我的」→「每日提醒」。
2. 点击「添加到 iPhone 日历」，会生成 `英语教练-每日提醒.ics`。
3. 在"文件"里点开它 → 选择"添加到日历" → 确认。
4. 之后每天到点，手机会像日程一样提醒你。

### 方法二：快捷指令自动打开

1. 打开 iPhone「快捷指令」App → 底部「自动化」→ 右上角「+」。
2. 选择「特定时间」→ 设置时间（比如 20:00）→ 每天 → 下一步。
3. 添加操作「打开 App」→ 选择「英语教练」→ 关闭"运行前询问"→ 完成。

## 四、跟读评分需要开启"听写"

设置 → 通用 → 键盘 → 打开「启用听写」。
如果没开启，跟读仍可用（会录音回放并给出节奏参考分），但无法做逐词识别。

## 五、常见问题

- **麦克风没反应？** 设置 → Safari → 麦克风 → 允许；首次使用时 App 会请求权限。
- **没有声音？** 检查侧边静音键；iOS 的静音状态会影响部分语音播放。
- **数据会丢吗？** 记录只存在这台手机里。更换手机或清理 Safari 数据前，
  请在「我的 → 数据备份」导出 JSON 文件。
- **想换一台手机？** 在新手机上打开同一个网址 → 我的 → 数据备份 → 导入。
- **怎么更新内容？** 应用会自动检查更新；也可以在「我的 → 安装与关于」里点"检查更新"。
